# Neo Mod Maker

A WorldBox mod creator for NML (Neo Mod Loader) that runs entirely in your browser. No install, no account, 100% free.

## Features

- Create traits, species, kingdoms, equipment, spells, buildings, powers and more
- Animated pixel editor and a built-in sprite library
- 13 site themes
- Exports a ready-to-use mod as a .zip
- Targets the latest WorldBox version

## How to use

1. Open the site: https://agrichex.github.io/Neo-Mod-Maker/
2. Build your mod
3. Export the .zip and place the mod folder in your WorldBox `Mods` folder (NML required)
